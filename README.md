This project was developed solely for **recruitment and educational purposes** as part of a technical test.

- All design assets, logos, and branding belong to their respective owners.
- This is **not** a commercial product and is not intended for public or commercial use.

## Stack

- **Framework:** Vue 3 (Composition API)
- **Build Tool:** Vite
- **Language:** TypeScript
- **Styling:** Tailwind CSS v4.0
- **Code Quality:** ESLint, ESLint Stylistic

## Getting Started

```bash
pnpm install   # Install dependencies
pnpm dev       # Run the app
```
